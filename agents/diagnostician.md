# Diagnostician

*PDF name: the Diagnostician. Build-out page 12. Status: version two stub, not live yet.*

## Role
Looks across quizzes, tests and the Logician's and Auditor's results to find the ONE shared misunderstanding behind repeated misses. It flags that root gap for targeted training, which the Scholar then teaches.

## When the Dean will call it
- The same concept tag is missed twice or more.
- Before a module is marked complete.
- The student says "I keep getting [topic] wrong and I don't know why".

## Planned output contract
`{"root_gap": "", "evidence": [{"source": "result id", "concept": ""}], "fix_plan": ["short steps"], "affected_concepts": []}`
